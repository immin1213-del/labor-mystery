# 진행자용 설명 화면(프로젝터 슬라이드) — 짧은 설계

## 의도
게임 시작 전 진행자가 프로젝터에 띄워 참가자 전원에게 진행 방법을 한 번 설명할 수 있게 한다. 지금 허브의 6줄짜리 "플레이 방법"은 너무 짧고, 3단계 문구는 현재 규칙(라운드당 토큰 2개·증거 36장·공개 카드 무료)과 맞지 않는다.

## 목표 / 비목표
- 목표: 전체 흐름을 한 번에 설명할 수 있는 15장 안팎의 화면 넘기기 페이지. 각 장은 게임 화면 모형 + 짧은 설명.
- 비목표: 세부 규칙 매뉴얼, 사건별 내용 설명, 참가자 개인용 튜토리얼, 게임 엔진 변경.
- 실패 기준: 실제 게임 화면·규칙과 다른 설명(예: 옛 "최소 채택" 규칙)을 보여주는 것.

## 접근 방법 (사용자 선택: 1)
1. **게임 사이트 안 새 페이지 `guide/index.html` (선택)** — 같은 링크로 바로 띄움, 게임과 같은 스타일의 HTML 모형이라 프로젝터에서 선명하고 게임 변경 시 같은 저장소에서 함께 수정. 단점: 문구 직접 수정은 어려움.
2. claude.ai 슬라이드 아티팩트 — PPTX 내보내기 가능하지만 사이트와 분리, 발표 PC 로그인 필요.
3. PowerPoint — 직접 편집 쉬움, 대신 정지 캡처라 게임 변경마다 다시 떠야 함.

## 결정된 것
- 프로젝터용(16:9 가로), 키보드 ←/→·스페이스·클리커(PageUp/PageDown)로 넘김, 전체화면 버튼, 장 번호 표시.
- 4개 사건 공통 1벌, 예시는 특정 사건이 드러나지 않는 가상 인물·증거.
- 구성(15장): 표지 / 게임 한눈에 / 전체 흐름표 / 입장 화면 / 배역 선택 / 상단바 / 내 신원 / 사건 개요 / 증거대①가져가기 / 증거대②공개하기 / 다음 단계로 넘어가는 법 / 교차검증 토론 / 최종 투표 / 결과 화면 / 시작 전 체크.
- 각 장: 왼쪽 게임 화면 모형(게임의 색·폰트·버튼 스타일 재사용) + 번호 표시(①②③), 오른쪽 설명 3~4줄. 깊이는 "전체적인 설명" 수준.
- 허브: "📽 진행자용 설명 화면" 버튼 추가, 기존 "플레이 방법" 3단계 문구를 현재 규칙으로 수정.

## 빌더에게 맡기는 것
- 모형의 세부 배치·문구 다듬기, 단계별 시간은 게임 `DURATIONS` 값과 일치시킬 것(개요 10분·자기소개 4분·라운드 5분×3·토론 15분·투표 2분).
